# سیستم ساخت بلوکی، ابزارها و منابع (پروتکل ۸)

## ایده
بازیکن مثل ماینکرفت با ابزار دست مواد جمع می‌کند و با آن‌ها هر چیزی (خانه، مزرعه، پل، مغازه، شهر دلخواه) می‌سازد. ساختمان‌های آماده (خانه، نانوایی...) هم کنار آن باقی‌اند.

## ابزارها (حالت زندگی، دکمهٔ «ابزارها»)
| ابزار | کار |
|---|---|
| تبر | لمس درخت ← چوب |
| کلنگ | لمس سنگ ← سنگ؛ لمس بلوک خود ← برداشتن (بازپرداخت کامل مواد) |
| بیل | خاک رس کنار ساحل؛ کندن زمین ← خاک/شن |
| چکش | گذاشتن بلوک انتخابی روی زمین یا کنار بلوک دیگر |
| قلم‌مو | رنگ‌آمیزی بلوک (۱۱ رنگ + طبیعی) |

## بلوک‌ها
خاک، چوب، سنگ، آجر، شیشه، پنجره، در، سقف، نرده، جاده، چراغ. هزینه در `scripts/core/const.gd` (`BLOCK_TYPES`).
- در و جاده قابل‌عبورند (در باید دو بلوک ارتفاع داشته باشد). روی یک بلوک تکی می‌شود ایستاد (کف/پله/پل)؛ دیوار دوبلوکی مانع است.
- بلوک باید روی زمین یا کنار بلوک دیگر باشد (روی آب فقط کنار ساحل/بلوک: پل).
- فقط مالک (یا مدیر) می‌تواند بلوک را بردارد یا رنگ کند. سقف ۲۵۰۰ بلوک برای هر بازیکن.
- میدان مرکزی فقط برای مدیر؛ زیر ساختمان‌ها نمی‌شود بلوک گذاشت و روی بلوک‌ها نمی‌شود ساختمان ساخت.

## منابع و درآمد
- درخت/سنگ/خاک رس به‌صورت قطعی از Seed بیرون شهر ساخته می‌شوند و پس از برداشت دوباره رشد می‌کنند.
- بازار مواد (دکمهٔ «کیف»): فروش مواد به سکه، خرید با ۱٫۸ برابر قیمت. با هر فروش قیمت کم و کم‌کم برمی‌گردد.
- ساخت مواد: ۲ خاک رس ← ۲ آجر، ۲ شن ← ۱ شیشه (ارزش افزودهٔ بیشتر).

## ذخیره و شبکه
بلوک‌ها، کیف، منابع برداشت‌شده و قیمت‌ها در `city.json` ذخیره می‌شوند (ذخیره‌های قدیمی بدون مشکل بارگذاری می‌شوند). RPCهای جدید: `c2s_place_block/remove_block/paint_block/gather/dig/craft/trade` و `s2c_inv/block/blocks/resource/depleted`. سرور همه چیز را بررسی می‌کند (فاصله، ابزار، مواد، مالکیت).
