# مقیاس ظرفیت جهان (پروتکل ۵۸)

مدیر هر جهان (در بازی آفلاین، خود بازیکن) می‌تواند سقف ساخت‌وساز را برای همان جهان چند برابر کند:
پنل مدیر ← «قوانین جهان» ← «ظرفیت ساخت‌وساز جهان» ← ×۱ / ×۲ / ×۴ / ×۸.

## چه چیزهایی مقیاس می‌گیرند
| سقف پایه | ×۱ | ×۸ |
|---|---|---|
| ساختمان برای هر بازیکن | ۴۰ | ۳۲۰ |
| بلوک برای هر بازیکن | ۲٬۵۰۰ | ۲۰٬۰۰۰ |
| کل بلوک‌های جهان | ۲۵٬۰۰۰ | ۲۰۰٬۰۰۰ |
| تغییرات زمین (رأس‌های ویرایش‌شده) | ۶٬۰۰۰ | ۴۸٬۰۰۰ |
| میدان بازی‌ساز (هر بازیکن / کل) | ۱۲ / ۸۰ | ۹۶ / ۶۴۰ |
| سقف زاد و ولد حیوانات (کل / هر گونه) | ۶۰ / ۳۰ | ۴۸۰ / ۲۴۰ (در سقف ۱۵۰ موجودات خدا می‌ماند) |

## چه چیزهایی عمداً مقیاس نمی‌گیرند
- سقف NPC و شخصیت‌های هوشمند (بار CPU دارند)، حجم یک عمل دسته‌ای و محدودهٔ جهان.
- ساخت‌وساز Creative برای سقف هر بازیکن همچنان آزاد است؛ سقف کل جهان در همهٔ حالت‌ها اعمال می‌شود.

## قواعد
- پیش‌فرض ×۱ است؛ جهان‌ها و ذخیره‌های قدیمی بدون تغییر بارگذاری می‌شوند.
- فقط مدیر می‌تواند عوض کند؛ سرور مقدار را اعتبارسنجی، ذخیره و همگام می‌کند (`c2s_set_world("cap_scale", n)`).
- کم کردن مقیاس چیزی را پاک نمی‌کند؛ فقط ساخت جدید تا رسیدن به سقف تازه ممنوع می‌شود.
- بارگذاری ذخیره هیچ‌گاه داده را به‌خاطر مقیاس بریده نمی‌کند.
- هشدار: ظرفیت بیشتر یعنی فایل ذخیرهٔ بزرگ‌تر و فشار بیشتر بر گوشی. اندازه‌گیری FPS روی گوشی واقعی هنوز انجام نشده است؛ تا آن زمان ×۱ پیش‌فرض می‌ماند.

تست: `test_capacity_scale` در `tests/unit_tests.gd`.
