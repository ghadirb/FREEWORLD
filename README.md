# FREEWORLD · جهان آزاد

بازی جهان‌باز سه‌بعدی، اشتراکی و آنلاین (Godot 4.3، GDScript، Low-Poly) با **سرور معتبر**.
بازیکنان در یک شهر مشترک زندگی می‌کنند، می‌سازند، کشاورزی و تجارت می‌کنند؛ NPCها برنامهٔ روزانهٔ مستقل دارند.

A shared 3D open-world sandbox (Godot 4.3) with an authoritative dedicated server, Persian-first UI (English included) and Android as the primary target.

## اجرای سرور

```bash
# سرور اختصاصی (بدون رندر)
FREEWORLD_ADMIN="admin:یک-رمز-قوی" \
godot --headless --path . -- --server --port 7777 --seed 12345 --data-dir /var/lib/freeworld
```

- پورت UDP را روی فایروال باز کنید (پیش‌فرض ۷۷۷۷).
- رمز مدیر را با متغیر محیطی بدهید (نه آرگومان) تا در فهرست پردازه‌ها دیده نشود. حداقل ۶ نویسه.
- داده‌ها در `city_1.json` (+ `.bak`) ذخیره می‌شود. اگر فایل خراب و بدون پشتیبان باشد، سرور **عمداً بالا نمی‌آید** تا داده با شهر خالی بازنویسی نشود.
- ذخیره‌سازی خودکار هر ۱۰ ثانیه و حداکثر ۱ ثانیه پس از هر تغییر مهم.

## اجرای بازی

1. APK یا فایل اجرایی را از بخش Actions → Artifacts بگیرید (یا پروژه را در Godot 4.3 باز کنید).
2. نام بازیکن، آدرس و پورت سرور را بزنید. توکن حساب خودکار روی دستگاه ذخیره می‌شود؛ حساب مدیر را با «رمز حساب» وارد کنید.

کنترل‌ها: **لمسی** — جوی‌استیک چپ، کشیدن برای چرخش/جابه‌جایی دوربین، دو انگشت برای زوم، لمس ساختمان برای اطلاعات.
**دسکتاپ** — WASD، ماوس (راست‌کلیک+کشیدن چرخش، چرخ زوم)، `M` یا `Tab` تغییر حالت، `Q/E` چرخش.

## امنیت (خلاصه)

سرور مرجع نهایی همهٔ داده‌هاست: هزینه، مالکیت، مجوز، سرعت حرکت، فاصلهٔ تعامل، سقف ساختمان و نرخ درخواست را خودش بررسی می‌کند؛
توکن‌ها فقط به‌صورت SHA-256 ذخیره می‌شوند؛ درخواست تکراری (`req_id`) دوبار هزینه نمی‌گیرد.
**ملاحظه:** ENet رمزنگاری ندارد؛ توکن بدون رمز روی شبکه می‌رود. برای انتشار عمومی باید DTLS یا تونل (مثلاً WireGuard) اضافه شود ([ROADMAP](docs/ROADMAP.md)).

مجوز فونت Vazirmatn: `assets/fonts/OFL.txt`.
